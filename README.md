# Speed gainer

In this videogame you help an astronaut to escape the cave he's been stuck in and be free. He needs to go as fast as possible and get to the end in a certain time to be able to move on.

He is equiped with the latest tech and is able to change gravity at will. Use it to take all of the slopes and achieve maximum speed.

## How to download the game

Clone the repository and open the project in unity. Then click play and try to free the astronaut.

## How to play

You can move to the left (A / <-) and right (D / ->) and switch gravity with *space*. Use the terrain and slide to achieve massive speeds and be free.
