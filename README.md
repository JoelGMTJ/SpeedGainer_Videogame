# Speed gainer
In this videogame you help ____ to escape the cave and be free. He needs to go as fast as possible and get to the end in a certain time to ____.

He can move, but specially he can change his gravity and use the terrain to get to speeds never seen before for ____.

## How to download the game
Clone the repository and open the project in unity. Then click play and try to ____ (escape the cave?).

## How to play
You can move to the left (A / <-) and right (D / ->) and switch gravity with _space_. Use the terrain and slide to achieve massive speeds and be free.
